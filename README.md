## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/VishnuBishnoi29/EyeHealthPredictor.git
cd EyeHealthPredictor
```

### 2. Create a virtual environment (recommended)

```bash
python -m venv venv
```

On Windows:

```bash
venv\Scripts\activate
```

### 3. Install dependencies

If the repository contains `requirements.txt`, run:

```bash
pip install -r requirements.txt
```

### 4. Run the project

Use the command appropriate for the actual project entry point. For example, if it contains `app.py`:

